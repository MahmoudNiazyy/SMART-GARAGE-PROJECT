# Smart Parking System

## Overview
The Smart Parking System is a prototype designed to monitor parking spaces and assist car owners in finding vacant parking spots. Utilizing the ARM Cortex-M4 microcontroller, this system integrates various components to provide real-time information to users.

## Features
- **Real-time Monitoring**: Detects available parking spaces.
- **User Interface**: LCD display for user interaction.
- **Input Method**: Keypad for user input.
- **Visual Indicators**: LED lights to indicate parking status.
- **Servo Motors**: Mechanism for physical parking guidance.
- **Communication Protocols**: Utilizes USART and SPI for interfacing with peripherals.
